# Reference index

The audit's rule set. Each file covers one thing to check on a landing page and lists its rules as checks, each with the reason it matters. Cite the file name when you report a finding.

## Files

- [landing-page.md](landing-page.md): first screen, CTAs, proof, section rhythm, mobile
- [hierarchy.md](hierarchy.md): focal points, emphasis, text tones, button tiers
- [typography.md](typography.md): type scale, line length, line height, alignment, tracking
- [color.md](color.md): palette size, contrast, color on color, accents
- [spacing.md](spacing.md): spacing scale, grouping, content width, responsive sizing
- [surfaces.md](surfaces.md): cards, shadows, borders, section backgrounds
- [images.md](images.md): product shots, text over photos, icons, logos
- [consistency.md](consistency.md): tokens, radius and personality, finishing details

## How to use them

Walk each file against the page and flag only real violations. Every rule says why it exists. Carry that reason into the finding so the fix reads as a reason, not a matter of taste. A rule can be broken on purpose: if the page clearly does something different and it works, leave it alone.
